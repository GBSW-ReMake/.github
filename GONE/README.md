# G · ONE

> **경북소프트웨어마이스터고(GBSW)의 여러 학생 서비스를, 하나(ONE)의 앱으로.**

실습실 신청, 외출 신청, 스쿨캠핑… 학교생활에 필요한 기능들이 여러 시스템에
흩어져 있었습니다. **GONE**은 이 모든 서비스를 하나의 앱으로 모아, 학생들이
필요한 정보를 빠르게 확인하고 반복적인 신청 절차를 간편하게 처리할 수 있도록
만드는 프로젝트입니다.

**G**BSW의 서비스를 하**ONE**으로 — 그게 이 프로젝트의 이름이자 목표입니다.

만들고 끝내는 프로젝트가 아닙니다. 학생이 직접 기획하고, 개발하고, 운영하고,
다음 학번에게 이어주는 것까지가 GONE의 원칙입니다. 그래서 코드 컨벤션, CI/CD,
설계 근거 하나하나를 문서로 남겨, 만든 사람이 졸업한 뒤에도 후배가 자연스럽게
이어받을 수 있는 구조를 지향합니다.
